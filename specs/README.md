# Specs

Fonte de verdade do produto. Cada arquivo cobre um assunto; não repita conteúdo entre eles, use links.

- `00`–`05`: specs do produto. São vivas: atualize a cada decisão.
- `features/NNN-<slug>.md`: spec de uma entrega, criada pela skill `create-specs` antes de implementar.
- `agentes/<agente>.md` (opcional): limita o que cada agente lê e pode decidir.
- `99-perguntas-em-aberto.md`: toda pendência ❓, numerada.

Convenção de pendência: `> ❓ **Pendente (#N):** <pergunta> — opções: A / B`. Ao decidir, escreva a regra no corpo do texto, remova o bloco e risque o item em `99`.
